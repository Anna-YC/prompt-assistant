预览图与视频下载存放的目录，可改到任意盘（如 D:\缓存）。留空时 Windows 用安装目录下的 cache\media，mac 用应用缓存目录。

使用说明

一、这套工具是做什么的

提示词助手是你的「提示词速查台」：把飞书多维表里积累的提示词、参考图、视频素材同步到电脑托盘， 随时一键复制、随时预览，不用再来回翻表格。

浏览器剪藏插件 ──存──▶ 飞书多维表（数据中台） ──同步──▶ 提示词助手（托盘/面板 取用·复制·预览）

二、配套：浏览器剪藏插件（负责“存”）

剪藏插件是一个浏览器扩展：平时浏览网页（社交平台、灵感站、作品站）时，遇到喜欢的图文提示词、封面图、视频， 点一下插件即可存入你自己的飞书多维表，可选择封面、微调提示词、打上分类标签。

  1. 安装：下载插件包解压 → 浏览器「扩展程序」页 → 「加载已解压的扩展程序」→ 选中解压文件夹；
  2. 准备多维表：打开「网页剪藏库」模板 → 先创建副本到自己空间（复制范围选“仅结构”）；
  3. 配置机器人：飞书开放平台创建企业自建应用 → 开通 bitable 相关权限并发布 → 在你的多维表「添加文档应用」中设为可编辑；
  4. 插件写入哪张表，本工具就同步哪张表（表名含「提示词」的表自动接入）。

三、本工具怎么用（负责“用”）

  1. 首次使用：设置 → 数据源 → 「环境自检」补齐依赖（可一键安装 lark-cli、跳转飞书登录）；
  2. 接入数据：粘贴你的飞书多维表链接 → 解析 → 立即同步；字段映射自动识别，一般无需手工配置；
  3. 日常取用：
    • 鼠标移到屏幕右缘悬浮把手上 → 面板滑出；移开自动收回，不打扰工作；
    • 两级分类浏览：大类（常用词 / 生图词 / 视频词 / 高频）→ 细分（人物 / 环境 / …）；
    • 点击卡片 = 复制提示词全文；点击封面图 = 放大预览；点击视频 ▶ = 内联播放；
    • 右键托盘图标 = 常用提示词菜单，点击即复制；左键托盘 = 固定展开面板；
    • 卡片 ★ = 加入「常用词」：同步出现在面板常用句页与托盘右键菜单；
    • 每次复制自动计数，「高频」分类按使用次数排序，方便复盘自己的常用库。
  4. 进阶：设置页可管理数据源与字段映射、新建本地提示词/常用句、切换主题与吸附边（右/顶）、 调整面板宽度与预览行数、更改媒体缓存位置或开启无痕模式。

四、数据都存在哪里

  • 提示词/图片/视频原文：你的飞书多维表（唯一数据源，本工具只读同步）；
  • 设置、加星、复制统计：本机系统应用数据目录（不随安装包分发）；
  • 预览图/视频缓存：默认安装目录 cache\media（mac 为应用缓存目录），可在「外观与行为」更改或清空。
